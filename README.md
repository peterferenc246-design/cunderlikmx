# Cunderlik MX Academy

Jednoduchý responzívny dvojjazyčný MVP web (SK/IT) pre motokrosovú školu, kempy a komunitu Emila Čunderlíka.

## Spustenie

```bash
npm install
npm run dev
```

## Nasadenie

Build pre statický hosting:

```bash
npm run build
```

Výsledok je v priečinku `dist/`. Pre Azure App Service alebo Static Web Apps sa dá napojiť GitHub repozitár a nasadzovať z vetvy `main`.

## Pred publikovaním

- Nahraď grafické plochy a iniciály reálnymi, licencovanými fotografiami Emila, tratí a kempov.
- Doplň e-mail, WhatsApp, reálny formulár a zásady ochrany osobných údajov.
- Doplň deväť jazykov: DE, EN, SK, FR, HR, PL, ES, IT, SV. Táto prvá verzia má hotové SK a IT ako prioritné jazyky.
